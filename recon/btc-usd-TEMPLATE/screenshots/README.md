# screenshots/

The `coinbase_recon` tool writes annotated PNG crops here at runtime:

- `full-page.png` — full Advanced Trade page capture.
- (future pass) per-region crops: order panel, order book, chart, trades tape,
  portfolio widget — each named by region, referenced from `RECON_REPORT.md`.

This directory is committed empty (this README) in the TEMPLATE because
screenshots require a live signed-in session on the operator's host.
